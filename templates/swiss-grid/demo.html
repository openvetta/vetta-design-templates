390 — index, headline, then the fields

  • Margin. 56px becomes 40px, then 20px. The rule stays 1px. A thinner rule, so the phone can “breathe,” removes the sheet.
  • Columns. Below 800px the row stacks: display index, headline, deck, then the meta. The meta is the side column that leaves first. The blank between deck and fields keeps a 36px floor and grows only when the sheet is shorter than the viewport.
  • Fields. Two columns from 520px to 799px, one column below 520px. The empty field keeps its index. It is not dropped to shorten the page.
  • Type. The display index goes 148, then 96, then 64. The headline goes 104, then 72, then 44. Body stays 16px. Labels stay 12px, and tracking tightens from 0.14em to 0.08em below 800px so the running head wraps inside the margin.
  • Targets. The composer stacks. Run becomes full width and stays 44px tall, as does the baseline. Nothing on the narrow sheet depends on a sideways scroll.
  • Pointer. The invert is limited to a fine pointer. A coarse pointer gets the same invert on press, then the control returns. The ink focus ring still shows for a keyboard.
  • Console. Time and name share a line. The sentence moves under them. The 2px signal rule stays on the left of the latest agent row.
