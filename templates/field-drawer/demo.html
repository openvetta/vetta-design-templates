01 — Board

Khaki, recess, eight faces

The board is the ground. The recess is darker, so the finds sit down into it. Oxide appears once, as the bench name. A voided find is a darker word, not a painted alarm.

02 — Tray

Blocks, not pictures

Four across, two down. Each block is one material from edge to edge. A lit top edge is the only modeling. Nothing is round, and nothing illustrates the bone it names.

03 — Type

Serif for the site, grotesque for the number

The site name is sentence case and quiet. Find numbers, depths, and the request are tracked capitals. The ledger repeats the tray in the same order.

04 — Request

An underline, not a badge

“Request the drawer” is a line of type with a target tall enough to hit. Hover changes its color. It does not grow a shape.
